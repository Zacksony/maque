## 五次明确可避免的放铳

### 1. 07-09，东三局：对手刚立直，摸到现物却打无筋牌

- 点数：`24000 / 25000 / 17000 / 34000`，Zackson 为座位 1。
- 座位 3 切 `6m` 立直；其可见牌河当时只有 `5z、6m`。
- 下一巡 Zackson 正好摸到另一张 `6m`，手牌仍是标准形三向听：

```text
67m 12468p 1224667s + 6m
```

- `6m` 是绝对现物；实战却切没有任何安全依据的 `1s`，放铳 6400。

这里不需要猜待牌，也不需要比较筋：三向听无打点依据，手里有现物，直接切 `6m` 弃和即可。这是最基础的现物识别错误。

### 2. 07-23，东二局：已经连续防守，最后一巡突然恢复摸切

- Zackson 当时第四。座位 3 切 `5m` 立直；座位 2 同时已经三副露，并有中、发两个确定役。
- 立直后前三巡处理正确：先切现物 `8s`，再连续切两张现物 `6p`。
- 最后一巡只剩约 4 张牌，摸到 `6s` 时手牌为：

```text
1237778m 3p 567899s
```

- 自己未听，手里仍有一张立直者已经打过的 `8s`。实战摸切 `6s`，不但无安全依据，还把向听数从一向听退到二向听，放铳 1300。
- 应继续切 `8s`。

这局说明问题不只是“不认识现物”，还包括**弃和执行到一半后失去纪律**。开始防守以后，除非手牌和局况发生足以重新进攻的变化，否则不能因为新摸到一张看起来普通的牌就恢复摸切。

### 3. 07-09，南三局一本场：一向听用生张宝牌顶两副露者

- 点数：`10100 / 16600 / 26900 / 46400`。Zackson 第三，领先第四 6500。
- 座位 0 已碰 `888s`、碰 `777p`，第 14 巡应按高概率接近听牌处理。
- 加杠后的宝牌指示牌包含 `2s`，因此 `3s` 是宝牌。
- Zackson 的结构为：

```text
副露：2222z（加杠） 444z（碰） 345p（吃）
手内：0m 6m 3p 4p 3s
```

- 自己只有一向听；`4p` 和 `6m` 都是座位 0 的现物。实战切生张宝牌 `3s`，放铳 8000，加一本场共损失 8300。
- 应切现物；其中切 `4p` 还能保留含赤五的 `56m`。

自己有役牌和赤五并不等于必须进攻。没有听牌、对手两副露、自己有现物，而且放铳会被第四名反超，四项都指向弃和。

### 4. 07-06，南二局：对公开满贯级威胁打无依据牌，同时降低向听数

- 点数：`32800 / 23000 / 29200 / 15000`，Zackson 第四。
- 座位 0 已碰中、碰 `666m`。两次杠后的宝牌信息使公开的 `666m` 成为 3 张宝牌；连同中，公开部分最低已经 4 番，是确定的满贯级威胁。
- Zackson 已大明杠 `777s`，摸 `5s` 后暗手为：

```text
12345m 3p 67p 55s6s
```

- 实战切 `1m`，从一向听退到二向听，并放铳 8000。
- 手牌中的 `7p` 是座位 0 现物，应直接用来弃和。即使只看牌效，切孤张 `3p` 或 `6s` 也能维持一向听，切 `1m` 没有牌效依据。

这是同时违反“最低打点计算、现物优先和不倒退向听数”的复合错误。

### 5. 07-07，东二局：千点级愚形听牌顶可见至少三番的庄家

- 点数：`25000 / 25000 / 16300 / 33700`。
- 庄家座位 1 已碰东、吃含赤五的 `345m`。东二庄家的东刻子同时是场风和自风，共 2 番，再加赤五，公开部分至少 3 番；两副露且已到第 12 巡。
- Zackson 已碰白、碰 `999p`、大明杠 `1111s`。最后摸 `2p` 时暗手为：

```text
8m 9m 2p 7s 7s
```

- 切 `2p` 可以维持坎 `7m` 听牌，但自己的确定打点只有白，另有一张宝牌 `9m`，总体仍是低价值愚形。
- 实战切 `2p`，放铳庄家 11600。
- 此处没有绝对现物，因此不能武断指定一张“必然安全牌”；但风险收益已经明确要求破听撤退。`9m`受庄家河中 `6m` 的筋保护，`8m`也已有两枚可见，都是只能称作相对低风险的撤退候选。

核心错误不是“没有猜中铳张”，而是用低价值愚形听牌顶可见高价值庄家。

## 不能按结果判错的放铳

### 无攻击信号的默听事故

- 07-07 东一：切 `8s` 后保持标准一向听，却撞到庄家门清七对子默听 9600。对手没有立直或副露信号；该切牌是正常牌效选择。
- 07-07 南四一本场：早巡切孤张 `6z`，撞到仅碰 `1m` 的对手默听 2300。对手没有确定高打点信号。
- 07-06 东一一本场、东四：对手均只有一副露、无立直、低可见打点；保持一向听进攻具有合理依据。

### 有足够收益依据的对攻

- 07-07 东一一本场：对手立直后，Zackson 已经听 `2s / 3s` 双碰，北、赤五和两张宝牌使自身至少满贯级；自己第四且无现物。切 `1s` 放铳 8300 属于高风险但有收益依据的进攻，不能简单判错。
- 07-06 东一：切 `4s` 立直形成 `2s / 5s` 两面，约 8 枚有效牌；对手虽两副露，但公开最低只有白 1 番。立直宣言牌被和 2000，是合理进攻的失败结果。
- 07-06 南四：庄家第四、仅 7000 点、落后第三 16000，面对两家立直仍完成坎 `8m` 听牌并立直。之后摸切 `3m` 放铳是立直后的强制行为；该局不进攻几乎只能确定第四，冒险有顺位依据。

### 正确防守却被另一家横移

- 07-07 东四：面对座位 0 立直，最终切其现物 `7p`，却被座位 1 无信号默听荣和 5200。最后一打本身是正确防守；真正可改进的是更早仍二向听时没有把剩余两张 `7p` 连续用于彻底弃和。

复盘时必须保留上述区分。目标不是“零放铳”，而是消灭没有收益依据、明明存在安全牌的放铳。

## 重复出现的牌效率问题

### 1. 保留孤张，拆对子或强复合形

- 07-23 东二：`1223778m 66p 3578s 3z`附近的牌形中，连续两次摸到 `3s` 又打掉，使二向听退为三向听；切孤张 `3z` 或整理冗余万子能保留二向听。当时 `3s`也不是防守牌，因此实战既没有牌效收益，也没有安全收益。
- 07-23 东四：`455688m 4468p 245s 6z` 中拆 `44p`，从二向听退为三向听；切孤张 `6z` 或整理冗余牌能维持二向听。
- 另一场 07-23 东三：`2334555m 357p 44s 99s` 为一向听，实战拆 `99s` 后退为二向听；切一张 `3m` 可以维持一向听。

### 2. 已有确定役后，仍过度保留孤张役牌

- 07-09 南一：已经碰白，手中有 `123m、666s、23s、12p` 等结构，却拆 `12p` 保留孤张发。已有白作为确定役，不需要为了第二个役牌牺牲有效搭子。

### 3. 无役副露

- 07-09 另一场南一：Zackson 为南家，却碰了西 `333z`。西既不是场风也不是自风，碰后仍二向听且没有确定役，只能依赖对对和等后续路线。这个碰关闭立直路线，却没有带来足够速度。

副露前应强制回答两个问题：

1. 碰/吃后是否已有确定役？
2. 副露后是否至少推进一向听，或显著增加有效牌？

任一项都不能满足时，原则上不副露。

## 做得好的决策

### 07-09 的 45000 点一位局可作为基准牌谱

- 13 小局和牌 5 次、放铳 0 次。
- 东二切 `4p` 立直，形成 `3m / 6m` 两面并荣和。
- 东四作为庄家碰双东，取得场风与自风两番，副露目的明确并快速和牌。
- 南二切 `7p` 立直，形成 `2s / 5s` 延单等待并荣和。
- 南三二本场七对子已有两张赤牌，选择默听 6400，保留撤退能力。
- 南四仅落后第一名 100 点且自己为庄家，切孤张 `3p` 立直，形成 `5p / 6p` 双碰并和牌，最终取得一位。

这场说明立直、默听、副露和顺位进攻都可以处理正确；当前问题是稳定性，不是完全不会。

- 07-07 另一场南三：手牌本身已经满贯级，选择默听荣和 8000，避免为不必要的额外打点增加风险。

从 7 月 6–7 日到 7 月 9–23 日，样本中的和牌率、放铳率和平均顺位都明显改善。但不能据此认定问题已经解决：8 月的放铳频率仍低于早期，然而四次大放铳再次来自同类判断——面对明显高价值威胁，自己未听或低价值听牌时仍继续进攻。

更准确的结论是：

- 基础做牌和立直判断进步较快；
- 防守有时能正确开始，但无法稳定执行到底；
- 对两副露、公开宝牌和庄家最低打点的计算仍不稳定；
- 纯牌效中的孤张、对子、复合形排序仍反复出错。

## 接下来最需要练习的流程

### 受到立直时

1. 立即报出自己的向听数。
2. 把手中全部现物列出来，不只找一张。
3. 按照“连续能安全走几巡”排序，而不是只处理当前一巡。
4. 二向听及以上、手里有现物时，原则上不重新进攻。

07-23 东二应作为固定训练题：已经切过 `8s、6p、6p` 防守，最后仍要记住手里还有第二张 `8s`。

### 面对副露时

每次对手达到两副露，计算：

```text
确定役番数 + 可见赤宝牌 + 可见普通宝牌 + 是否庄家
```

公开 4 番或庄家公开 3 番时，应按满贯级威胁处理。自己未听时不打生张宝牌和无筋中张。

### 牌效率

每巡重新标记：

```text
完整面子 / 雀头 / 搭子 / 孤张 / 第六组以上冗余牌
```

出牌后再问一次：“向听数是否倒退？若倒退，这是为了安全、打点还是顺位？”三个理由都没有，就不应这样切。

### 未来 20 个半庄的过程指标

1. “立直后手里有现物却打无筋牌”：目标 0 次。
2. “自己未听，向公开满贯级两副露者放铳”：目标 0 次。
3. “副露后无确定役且未明显推进”：目标 0 次。
4. 每次立直前继续计算等待种类和剩余枚数。
5. 每局只记录三个检查点：首次两副露、首次立直、自己首次一向听。用这些节点复盘攻守转换，不需要记录每一打。

## 总结

这批早期牌谱强化了上一批复盘的结论，但给出了更精确的优先级：

1. 第一优先不是复杂读牌，而是现物识别与弃和执行到底。
2. 第二优先是计算副露者的公开最低打点。
3. 第三优先才是孤张、对子和复合形的牌效率。

当前已有多场证据表明能够做出正确的好形立直、价值默听和顺位进攻。提升段位的关键，是让“什么时候停止进攻”像“什么时候立直”一样成为固定流程。
